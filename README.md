# **BikePoint - Sistema de gestión para el taller de bicicletas**

## Descripción del proyecto

Este proyecto consiste en desarrollar un sistema que permita organizar y administrar la información de un taller de bicicletas. El proyecto llevará el control de clientes, bicicletas, mecánicos, órdenes de servicio, reparaciones, refacciones y pagos, facilitando el seguimiento de cada trabajo realizado.

### **Funciones previstas**

- Registrar clientes y sus bicicletas.
- Crear y consultar órdenes de servicio.
- Registrar el diagnóstico y las reparaciones realizadas.
- Asignar órdenes de trabajo a los mecánicos.
- Controlar los servicios y las refacciones utilizadas.
- Actualizar el estado de la bicicleta.
- Registrar pagos y consultar el costo total del servicio.
- Consultar el historial de reparaciones de una bicicleta.
